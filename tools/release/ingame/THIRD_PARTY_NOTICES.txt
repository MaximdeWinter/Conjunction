In bin\x64_dx12\tw3se\mods\conjunction (Lua):

The Lua files do what Conjunction's Python code did, with Python's own rules where the results have to be the same:
regular expressions, sorting, numbers, text and difflib (difflib.lua, pyre.lua, pyrandom.lua) follow CPython 3.14 -
Python Software Foundation - PSF License (licenses/Python.txt). yaml.lua writes YAML as PyYAML 6.0.3 does - Kirill
Simonov, Ingy dot Net - MIT (licenses/PyYAML.txt).
The windows are laid out and behave as Qt 6.11's widgets (ui/layout.lua, ui/qw.lua, ui/itemview.lua, ui/lineedit.lua,
  ui/spinbox.lua, ui/textlayout.lua, qtbreak.lua and the character data in data/qt_unicode.lua follow Qt 6.11's
  source) - The Qt Company Ltd. - LGPL-3.0 (licenses/LGPL-3.0.txt). These files are their own source code.

  Unicode License v3 (licenses/Unicode.txt)
