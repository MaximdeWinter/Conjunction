Conjunction Runtime

For quests made with Conjunction. Every Conjunction quest runs on its own. A quest can change the game's own world,
for example hide a villager, switch off a group of monsters or lock a door. When you remove the quest, the runtime
puts these back as they were, as soon as you come near them.

Install it once. It works for every Conjunction quest.

Install: unpack the zip into the game folder (the one with bin, content, dlc), or use a mod manager. You now have
Mods\modConjunctionRuntime. Conjunction itself brings it already.

Uninstall: delete Mods\modConjunctionRuntime.
